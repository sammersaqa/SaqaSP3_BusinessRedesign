## Project Name
Legacy Lawn Care & Landscaping - Multi-Page Business Website

## Project Description
A professional, responsive business website for Legacy Lawn Care & Landscaping, a Stockton-based lawn care and landscaping service. The website features a modern design with Bootstrap 5 framework and includes multiple pages showcasing the company's services, background, and contact information.

### Key Features:
- **Home Page:** Hero section with background image, call-to-action button, and quote request modal
- **About Page:** Owner biography with professional photo and client testimonials
- **Services Page:** Grid layout displaying 9 different services with images and quote request functionality
- **Contact Page:** Full-page background with contact form and validation
- **Responsive Design:** Mobile-first approach with breakpoints for tablets and desktop devices
- **Interactive Elements:** Bootstrap modals, form validation, and hover effects

### Technologies Used:
- HTML5
- CSS3 (Custom styles with media queries)
- Bootstrap 5.3.0
- JavaScript (Form validation and interactivity)
- Font Awesome 6.5.0 (Icons)

### Page Structure:
- `index.html` - Home/Landing page
- `pages/about.html` - About Us page
- `pages/services.html` - Services page
- `pages/contact.html` - Contact page
- `styles/styles.css` - Global stylesheet
- `scripts/script.js` - JavaScript functionality
